对输入文本chunkify，并parallelize。我的直觉实现是：确认切割文本的位置，给每个task一个offset，每个子进程自行去文件中读取。为什么开源实现中是直接读取文件内容并输出给各个subprocess：
AI回答：
```
chunk_bytes = f.read(end - start)
```
Here, the code iterates over pairs of start and end indices from the boundaries list. These indices determine where each chunk begins and ends.


with open(input_path, "rb") as f:
   boundaries = find_chunk_boundaries(

   chunk_args = []
   for start, end in zip(boundaries[:-1], boundaries[1:]):
      f.seek(start)
      chunk_bytes = f.read(end - start)
